# Interactive Portfolio Website

An interactive developer portfolio web application built with React and Vite that integrates the public GitHub REST API to display user profile information and public repositories.

## Technology Stack

- React.js
- Vite
- JavaScript (ES6+)
- HTML5
- CSS3
- GitHub REST API

## Installation

Install project dependencies using npm:

```bash
npm install
```

## Running Locally

Start the local development server:

```bash
npm run dev
```
